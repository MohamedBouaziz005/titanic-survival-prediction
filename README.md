# Titanic Survival Prediction

## Description
Ce projet consiste à analyser les données des passagers du Titanic et à utiliser le Machine Learning pour prédire leur survie.

## Objectifs
- Nettoyer et préparer les données.
- Réaliser une analyse exploratoire (EDA).
- Étudier les facteurs associés à la survie.
- Entraîner et comparer plusieurs modèles de Machine Learning.

## Technologies utilisées
- Python
- pandas
- matplotlib
- scikit-learn
- Jupyter Notebook

## Modèles utilisés
- Logistic Regression
- Random Forest

## Résultats
Le modèle Random Forest initial a obtenu une Accuracy de **81,56 %** sur les données de test. La validation croisée à 5 folds a donné une Accuracy moyenne de **81,37 %**.

## Fichiers du projet
- `titanic_analysis.ipynb` : notebook contenant le nettoyage, les analyses, les graphiques et les modèles.
- `train.csv` : données utilisées pour l'entraînement et l'évaluation.
